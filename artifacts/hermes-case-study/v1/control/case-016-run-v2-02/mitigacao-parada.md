# Mitigação linha 3

1. Alarme de pressão alta em PS-9: reduza a carga.
2. Se P-52 parar e XV-140 ficar aberta, o fluxo vai ao dreno.
3. Isole XV-140. Aguarde PS-9 na faixa normal.
4. Se LS-03 indicar nível baixo no tanque de amortecimento, complete com água de processo.
5. Parta P-52 com carga reduzida. Abra XV-140 devagar.
6. Observe PS-9 dez minutos. Libere a linha.
7. Inspecione PS-9 na próxima parada.
