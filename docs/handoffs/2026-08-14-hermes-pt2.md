## Decisions made

- Português brasileiro é o único idioma de produto; o inglês não evolui.
- O nome aceito é **HERMES**; pacote alvo `hermes_lint`, CLI `hermes`, IDs
  `HERMES-PT-*`.
- Os nomes humanos dos modelos são **Sabiazinho 4** e **Sabiá 4 Thinking**; os
  aliases de API registrados são `sabiazinho-4` e `sabia-4-thinking`.
- `HERMES-PT-PONT-001` é a primeira regra candidata e proíbe `;` literal em
  prosa lintável; permanece `info/preview` e sem autofix até evidência.
- O lote de desenvolvimento tem 12 `violation`, 12 `non_violation`, 12
  `out_of_scope` e 4 `ambiguous`; SHA-256
  `51f52007848deaae5169171354d900488df9faedbf073a17a48b14d714703bfc`.
- Kubernetes pt-BR é a fonte recomendada do primeiro holdout porque oferece
  Markdown versionado e CC BY 4.0. Python e GitHub Docs exigiriam transformação
  de PO/HTML e ficaram para tranches futuras.

## Constraints

- Não traduzir ou reutilizar texto, exemplos, obrigações ou IDs da ASD-STE100.
- Não consultar o detector durante rotulagem nem usar labels do holdout para
  ajustar regra, prompt, threshold ou fixture.
- Não enviar documentos a Maritaca sem opt-in explícito por execução.
- Não gerar manifesto ou labels do Kubernetes antes da aprovação da avaliação
  de fonte.

## Attempts not to repeat

- `git sparse-checkout set content/pt-br LICENSE README.md` tratou `LICENSE`
  como diretório; o checkout correto usou modo `--no-cone` com caminhos
  absolutos do sparse spec.
- Python pt-BR não é entrada direta do parser atual: a fonte de tradução é PO.
  Não converter para texto sem contrato próprio de transformação e offsets.
