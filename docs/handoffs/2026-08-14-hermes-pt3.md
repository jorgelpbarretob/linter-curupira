instalado. O corpus sintético de desenvolvimento passou em 36/36 casos com
decisão aplicável; 4 casos `ambiguous` não são usados como expectativa. Ruff,
formatação, mypy estrito e `git diff --check` passaram antes do handoff. Um wheel

código privado PT3. Nenhum path de código foi enviado nessa tentativa. Nenhum
detector foi executado no holdout e os labels de custódia não foram abertos.

## Decisions made this session

- Migrar os contratos para `hermes_lint` sem imports de `ste_lint` → o wheel
  público não carrega catálogo, defaults ou modelos ingleses.
- Manter `HERMES-PT-PONT-001` desabilitada por padrão como `preview/info` → a
  promoção depende da avaliação isolada ainda não executada.
- Excluir URLs, código, metadados, comentários HTML, elemento `<code>` e spans
  matemáticos suportados antes da regra → atende os casos adjudicados de
  desenvolvimento sem inferência semântica.
- Preservar CRLF na leitura da CLI e usar offsets por ponto de código Unicode →
  mantém o contrato lossless migrado.
- Não contornar o bloqueio de egress da revisão Grok → código privado só será
  transmitido após aprovação humana específica.
